<section class="project">
  <h2>Product Store – Full Stack Web Application</h2>
  <p>
    Complete e-commerce style application with REST API backend and interactive frontend.
  </p>

  <h3>Overview</h3>
  <p>
    Product Store is a full-stack web application that manages products,
    customers and purchase orders. It includes a RESTful API built with
    Express and a frontend interface that consumes the API.
  </p>

  <h3>Backend</h3>
  <ul>
    <li>Node.js + Express</li>
    <li>Sequelize ORM</li>
    <li>SQLite database</li>
    <li>Relational data modeling (Customers, Orders, Products)</li>
  </ul>

  <h3>Frontend</h3>
  <ul>
    <li>HTML, CSS, Vanilla JavaScript</li>
    <li>API consumption via Fetch</li>
    <li>Dynamic UI updates</li>
  </ul>

  <h3>Architecture</h3>
  <p>Layered architecture with clear separation between routes, models and configuration.</p>
</section>
